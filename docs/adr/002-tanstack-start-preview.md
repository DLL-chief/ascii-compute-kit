# 002. Каркас приложения — TanStack Start на превью-платформе

* Статус: принято
* Дата: 2026-09-14
* Сменяет: не отменяет ADR-001 для GitHub как канона репозитория

## Контекст

Контракты compute не зависят от фреймворка. Живое превью в среде Grok Build требует TanStack Start + Vite. Статический `index.html` там не поднимает превью.

## Решение

* Ядро, detect, pipeline, backends — чистые модули в `src/` этого репозитория.
* UI превью — React (`src/ui/ascii-studio.tsx` как снимок).
* Wasm встроен в `src/ascii/wasm-bytes.ts`, исходник `wasm/ascii.rs`.
* Auth и БД не подключаем.

## Последствия

Репозиторий — исходники шаблона. GitHub Pages из голого HTML — отдельный шаг, когда понадобится зеркало без бандлера.
