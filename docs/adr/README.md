# Architecture Decision Records

Формат: `NNN-краткий-кебаб.md`.
Нумерация сквозная, без дыр.
Принятый ADR не редактируют. Если решение изменилось — пишут новый ADR, который ссылается на старый.

Шаблон тела:

* Статус
* Контекст
* Решение
* Последствия
