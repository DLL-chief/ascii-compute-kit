# docs/

Папка для решений и карт, которые живут дольше кода.

| Файл | Зачем |
| --- | --- |
| `architecture.md` | Компоненты, потоки данных, что будет в `src/` |
| `api_contracts.md` | Контракты между UI, pipeline и compute-бэкендами |
| `adr/` | Нумерованные решения. Файлы не редактируют задним числом |

Как читать:

1. Архитектура — если нужно понять систему.
2. Контракты — если пишешь или меняешь модуль compute.
3. ADR — если хочешь изменить уже принятое решение.
