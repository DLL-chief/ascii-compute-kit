# Правила для ИИ-агентов

Документ обязателен для Claude, Grok, Codex и любого другого агента, который пишет в этот репозиторий.

## 1. Состояние работы

Перед любой задачей прочитай `STATUS.md`. Не предлагай заново то, что уже решено в ADR или отмечено как сделанное. Если задача меняет спринт, блокеры или следующий шаг — обнови `STATUS.md` в том же изменении.

## 2. Документация важнее «набросать файлы»

* Не оставляй пустые README и заглушки «TODO later». Либо заполни, либо не создавай.
* Плейсхолдеры вида `<...>` запрещены.
* Новый модуль в `src/` появляется вместе с `src/<module>/README.md`.
* Решение, которое меняет стек, хостинг или контракт бэкендов — новый файл в `docs/adr/`. Старые ADR не переписывать.

## 3. Код

Код писать можно. Контракт `docs/api_contracts.md` обязателен. Не ломай `run({ rgba, w, h, options })` без ADR.

* Воркеры — same-origin. Wasm: `fetch` или встроенные байты `src/ascii/wasm-bytes.ts`.
* Не требовать SharedArrayBuffer.
* UI на русском.
* Ядро в `src/ascii` не зависит от React. React-снимок — `src/ui`. GitHub Pages — `index.html` + `pages/` (ADR-003). Тумблер Pages включает владелец (ADR-004).


* После правки ядра/воркера/пайплайна: `bash scripts/build-pages.sh` и закоммитить `pages/app.js`, `pages/compute.worker.js`.

## 4. Язык и стиль

* Коммиты и PR — по-русски: `docs: ...`, `feat: ...`, `fix: ...`.
* Секретов нет.

## 5. Порядок чтения для агента

1. `AGENTS.md` и `CLAUDE.md`.
2. `STATUS.md`.
3. `README.md` + `docs/architecture.md` + `docs/api_contracts.md`.
4. Нужный `src/<module>/README.md`.
5. ADR — если меняется устройство системы.
