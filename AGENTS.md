# Правила для ИИ-агентов

Документ обязателен для Claude, Grok, Codex и любого другого агента, который пишет в этот репозиторий.

## 1. Состояние работы

Перед любой задачей прочитай `STATUS.md`. Не предлагай заново то, что уже решено в ADR или отмечено как сделанное. Если задача меняет спринт, блокеры или следующий шаг — обнови `STATUS.md` в том же изменении.

## 2. Документация важнее «набросать файлы»

* Не оставляй пустые README и заглушки «TODO later». Либо заполни, либо не создавай.
* Плейсхолдеры вида `<...>` в этом репозитории запрещены: проект уже конкретный.
* Новый модуль в `src/` появляется вместе с `src/<module>/README.md`.
* Решение, которое меняет стек, хостинг или контракт бэкендов, оформляется новым файлом в `docs/adr/` (следующий номер). Старые ADR не переписывать.

## 3. Сейчас код писать нельзя

Текущий этап (см. `STATUS.md`): только документация и контракты. Не добавляй `index.html`, JS, шейдеры, `.wasm`, сборку. Исключение — сам владелец явно попросил следующий шаг «писать код по документации».

Когда код разрешён:

* Держи контракт `docs/api_contracts.md`. Не ломай сигнатуру `run(rgba, w, h)` без нового ADR.
* Относительные пути: сайт будет на `https://dll-chief.github.io/ascii-compute-kit/`.
* Воркеры — same-origin. Wasm грузить через `fetch` + `instantiate`, не полагаться только на streaming MIME.
* Не требовать SharedArrayBuffer.
* Не подключать фреймворк и пакетный менеджер без ADR.
* UI на русском, как и документация.

## 4. Язык и стиль

* Коммиты и PR — по-русски, кратко: `docs: ...`, `feat: ...`, `fix: ...`.
* Не выкладывай секреты. В этом проекте секретов нет.
* Не раздувай объём. Шаблон должен оставаться читаемым за один вечер.

## 5. Порядок чтения для агента

1. `AGENTS.md` (этот файл) и `CLAUDE.md`.
2. `STATUS.md`.
3. `README.md` + `docs/architecture.md` + `docs/api_contracts.md`.
4. Нужный `src/<module>/README.md`.
5. ADR — только если меняется устройство системы.
