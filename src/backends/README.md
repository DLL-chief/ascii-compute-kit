# src/backends

Ответственность: реализация интерфейса `Backend`.

Планируемые адаптеры:

* `js-main` — ядро в главном потоке, эталон для сверки пикселей.
* `js-worker` — то же ядро в Worker.
* `wasm-worker` — ядро на Wasm внутри Worker.
* `webgpu` — WGSL, атлас глифов или генерация растра в storage buffer.
* `webgl2` — запасной GPU-путь.

Не делают: не ходят в DOM. Не меняют контракт `run` без ADR.
