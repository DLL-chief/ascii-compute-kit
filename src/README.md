# src/

Кода модулей пока нет. Здесь живут README будущих модулей, чтобы агент и человек понимали границы до появления файлов реализации.

Конвенция:

* Один модуль — одна папка — один `README.md`.
* README модуля описывает ответственность, входы/выходы и чего модуль не делает.
* Реализация появится рядом с README, не вместо него.
* Не класть в `src/` сгенерированный бандл и `node_modules`.

Модули первой очереди:

| Папка | Роль |
| --- | --- |
| `detect/` | Опрос возможностей браузера |
| `pipeline/` | Оркестрация бэкендов и тайминг |
| `backends/` | Адаптеры js-main, worker, wasm, gpu |
| `ascii/` | Ядро фильтра: яркость → символ → растр |
